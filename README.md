# About the repository
Projects involving FPGA, used for hardware acceleration, image processing, and anything with FPGA.

Hardware acceleration only helps when the application and implementation is justified with respect to a conventional processor and DSP based methods.
FPGA are used for high speed, parallel, and high bandwidth applications like Digital Modems, Image processing...

Each folder represents a separate project, hence each directory contains a readme.md file for specific details.
